# Decisões de implementação

- React + Vite + TypeScript, conforme escolha de Eric na conversa.
- Conteúdo prioritariamente comercial, com caminhos de aprofundamento úteis a recrutadores.
- Home com áreas de atuação, dois projetos de naturezas explicitamente diferentes, biografia factual, método, artigo em destaque e contato confirmado.
- Português como idioma padrão e inglês com URLs próprias. Seletor aponta para a página equivalente.
- Navy & Glacier, Inter e Source Serif 4. Diagramas próprios; nenhuma foto de banco de imagens ou retrato inventado.
- Artigos MDX e dados de exemplo versionados junto ao código. Sem CMS, autenticação ou banco de dados nesta etapa.
- Pré-renderização com a API React e o build SSR do Vite: rotas conhecidas geram HTML estático. Navegação entre documentos por links normais; não há router de aplicação nem fallback de SPA necessário.
- Visualização SVG com controles React; cálculo de margem por totais, tabela e CSV. A demonstração não é um case de cliente.
- Fluxo DEV/main e gate de aprovação pessoal preservados. Workflow de publicação preparado, mas nenhuma configuração de Pages ou conteúdo de main alterado.
- Conteúdo a complementar quando houver evidências: currículo, experiência com datas/cargos, foto real, screenshots e resultados dos projetos. Não inserir placeholders públicos ou resultados fictícios.
