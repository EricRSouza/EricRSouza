Posts are MDX: Markdown that can import components. Text works as usual, and any React component can run inside the post. `client:visible` loads it only when the reader scrolls to it.

The numbers above are illustrative. The same pattern works for a chart library, a DuckDB query over a Parquet file, or a full dashboard.
